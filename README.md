# Student Attendance Management System

## Description

A simple database application for managing student attendance.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## Features

- Add students
- Mark attendance
- View attendance
- Store attendance in a database

## Database

The application uses SQLite.

## Tables

### Students

- student_id
- name
- register_no
- department

### Attendance

- attendance_id
- student_id
- subject
- attendance_date
- status

## How to Run

1. Install Python.
2. Create a virtual environment.
3. Install Flask.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000`.
